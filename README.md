# ELVIS — Electric Vehicle Charging Infrastructure Simulator

ELVIS simulates charging sites: when vehicles arrive, how long they park, how much energy
they need, and how a scheduling policy shares limited grid capacity between them. It produces
load profiles and KPIs (energy, peak load, simultaneity, rejections, cost, emissions) for
infrastructure planning and grid-impact studies.
